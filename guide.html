🏪 Butiran KedaiStore Details

Tab Kedai mengawal butiran yang pelanggan lihat pada halaman menu.

The Store tab controls the details customers see on the menu page.

Toggle Buka / TutupOpen / Closed Toggle

1
Log masuk dengan PIN Pemilik anda.
Log in with your Owner PIN.
2
Ketik tab Kedai.
Tap the Store tab.
3
Guna suis Kedai Buka. Menu pelanggan dikemas kini serta-merta.
Use the Store is Open switch. The customer menu updates immediately.
Penting:Important: Apabila tutup, pelanggan nampak amaran dan tidak boleh tambah item ke troli. Buka semula kedai apabila anda bersedia terima pesanan. When closed, customers see a warning and cannot add items to cart. Re-open the store when you are ready to receive orders.

📋 Urus MenuManaging the Menu

Tab Menu membolehkan anda tambah, edit, padam, dan tandakan item sebagai habis dijual.

The Menu tab lets you add, edit, delete, and mark items as sold out.

Tandakan Item Habis DijualMark an Item as Sold Out

1
Cari item dalam senarai.
Find the item in the list.
2
Ketik Habis Dijual. Pelanggan akan nampak item berkeadaan redup dan tidak boleh mengesanya.
Tap Sold Out. Customers will see the item greyed out and cannot order it.
3
Ketik Aktifkan untuk jadikannya tersedia semula.
Tap Enable to make it available again.

Tambah Item BaruAdd a New Item

1
Ketik + Tambah Item.
Tap + Add Item.
2
Isi kategori, nama, penerangan, emoji, dan foto pilihan.
Fill in category, name, description, emoji, and optional photo.
3
Untuk minuman, masukkan harga Panas, Sejuk, atau Frappé. Kosongkan saiz untuk sembunyikannya.
For drinks, enter Hot, Cold, or Frappe prices. Leave a size blank to hide it.
4
Untuk makanan, masukkan satu harga tetap.
For food, enter one fixed price.
5
Ketik Tambah Item.
Tap Add Item.

Edit, Padam, dan KategoriEdit, Delete, and Categories

  • ✏️ Ketik Edit di sebelah item untuk tukar butiran, harga, foto, dan tambahan.Tap Edit beside an item to change details, prices, photos, and add-ons.
  • 🗑️ Ketik Padam hanya apabila anda betul-betul mahu buang item.Tap Del only when you really want to remove an item.
  • 🏷️ Guna Kategori untuk menamakan semula label kategori atau tambah kategori baru.Use Categories to rename category labels or add a new category.

📦 Lihat PesananViewing Orders

Tab Pesanan menunjukkan log pesanan yang dihantar melalui WhatsApp, terbaru dahulu.

The Orders tab shows a log of orders sent through WhatsApp, newest first.

Setiap entri menunjukkan nama pelanggan, masa, item yang dipesan, tambahan, dan anggaran jumlah.

Each entry shows customer name, time, items ordered, add-ons, and estimated total.

Tip: Ini adalah log rujukan. Perbualan sebenar dan pemenuhan pesanan masih berlaku dalam WhatsApp. This is a reference log. Actual conversation and fulfilment still happen in WhatsApp.

Ketik Muat Semula untuk memuatkan pesanan terkini. Aplikasi menyimpan sehingga 1,000 rekod pesanan.

Tap Refresh to reload latest orders. The app keeps up to 1,000 order records.

🎨 Studio TemaTheme Studio

Studio Tema menukar penampilan menu: warna, fon, dan reka letak kecil. Ia menggunakan AI hanya apabila anda berbual dengan pembantu reka bentuk.

Theme Studio changes the menu appearance: colours, fonts, and small design tweaks. It uses AI only when you chat with the design helper.

Perlukan persediaan:Requires setup: Pembangun mesti simpan kunci API OpenRouter dalam tab Pembangun sebelum sembang berfungsi. The developer must save an OpenRouter API key in the Dev tab before chat works.

Tukar Tema Melalui SembangChange Theme by Chat

1
Ketik Studio Tema.
Tap Theme Studio.
2
Taip permintaan ringkas, contohnya: "Jadikan ia kelihatan seperti kafe yang selesa".
Type a simple request, for example: "Make it look like a cosy cafe".
3
Ketik Hantar. Jika anda suka hasilnya, simpan. Jika tidak, pulihkan tema terakhir yang disimpan.
Tap Send. If you like the result, keep it. If not, restore the last saved theme.

Set Semula KilangFactory Reset

Log masuk pembangun boleh memulihkan tema utama asal jika reka bentuk menjadi tidak kemas atau tidak boleh dibaca.

Developer login can restore the original master theme if the design becomes messy or unreadable.

🔒 Keselamatan & PINSecurity & PINs

Tukar PIN PemilikChange Owner PIN

1
Pergi ke tab Keselamatan.
Go to the Security tab.
2
Masukkan PIN 4 digit baru dua kali.
Enter the new 4-digit PIN twice.
3
Ketik Kemas Kini PIN Pemilik.
Tap Update Owner PIN.
Tulis ia.Write it down. Jika PIN Pemilik dan PIN Pembangun hilang, pembangun anda perlu tetapkan semula terus dalam Firebase. If both Owner PIN and Developer PIN are lost, your developer must reset it directly in Firebase.

Tukar PIN PembangunChange Developer PIN

PIN Pembangun boleh ditukar dari tab Keselamatan hanya apabila log masuk sebagai pembangun.

Developer PIN can be changed from the Security tab only when logged in as developer.

🌐 Tukar BahasaLanguage Toggle Baru

Menu pelanggan, panel admin, dan panduan ini semuanya menyokong Bahasa Malaysia dan Bahasa Inggeris. Bahasa Malaysia adalah lalai.

The customer menu, admin panel, and this guide all support Bahasa Malaysia and English. Bahasa Malaysia is the default.

Menu PelangganCustomer Menu

Ketik butang EN di bar atas di sebelah togol Cerah/Malam untuk tukar ke Bahasa Inggeris. Ketik BM untuk kembali ke Bahasa Malaysia. Pilihan disimpan dalam pelayar.

Tap the EN button in the top bar beside the Light/Night toggle to switch to English. Tap BM to return to Bahasa Malaysia. The choice is saved in the browser.

Panel AdminAdmin Panel

Butang bahasa muncul di skrin PIN (sudut kanan atas) dan dalam bar atas selepas log masuk. Kedua-duanya menggunakan keutamaan yang sama.

The language button appears on the PIN screen (top right) and in the top bar after login. Both share the same preference.

Tip: Tetapan bahasa dikongsi merentas semua halaman — tukar sekali, semua halaman ikut. Language is shared across all pages — change it once, all pages follow.

🛟 Pemulihan & Penyelesaian MasalahRecovery & Troubleshooting

🔑
PIN Pemilik Dilupakan
Forgotten Owner PIN

Log masuk dengan PIN Pembangun → tab Keselamatan → kemas kini PIN Pemilik.

Log in with Developer PIN → Security tab → update the Owner PIN.

🎨
Tema Kelihatan Salah
Theme Looks Wrong

Log masuk dengan PIN Pembangun → Studio Tema → pulihkan tema terakhir yang disimpan atau set semula kilang.

Log in with Developer PIN → Theme Studio → restore last saved theme or factory reset.

🌐
Halaman Tidak Memuatkan
Page Not Loading

Semak sambungan internet. Aplikasi memerlukan Firebase untuk memuatkan menu dan tetapan langsung.

Check internet connection. The app needs Firebase to load live menu and settings.

⚙️
Ralat Sembang Studio Tema
Theme Studio Chat Error

Log masuk Pembangun → tab Pembangun → semak kunci API, model yang dipilih, dan Log Ralat.

Developer login → Dev tab → check API key, selected model, and Error Log.

Perlukan bantuan? Hubungi pembangun anda.Need help? Contact your developer.
