🗺️ What Opens What

🛠️
admin.html
Owner and developer control panel

Use this page to change store info, menu items, availability, orders, PINs, and Theme Studio settings.

📱
index.html
Customer-facing menu

This is what customers open to browse the menu and send orders through WhatsApp.

Tip: After saving in admin.html, refresh index.html to check what customers will see.

🔐 Logging In

Open admin.html on your phone or computer. You will see a 4-digit PIN screen.

🏪
Owner PIN
For daily store operation

Use it for store details, menu management, orders, Theme Studio, and Owner PIN changes.

🛠️
Developer PIN
For setup and recovery

Everything above, plus Dev tools, API keys, model settings, error logs, and master theme snapshot.

Tip: If you enter the wrong PIN, wait 2 seconds and try again. PINs are stored in Firebase, not in the browser.

🏪 Store Details

The Store tab controls the details customers see on the menu page.

Open / Closed Toggle

1
Log in with your Owner PIN.
2
Tap the Store tab.
3
Use the Store is Open switch. The customer menu updates immediately.
Important: When closed, customers see a warning and cannot add items to cart. Re-open the store when you are ready to receive orders.

Update Store Info

In the Store tab you can edit:

Store NameShown at the top of the menu
SloganShort line below the name
Opening HoursShown under the header
WhatsApp NumberCountry code + digits only
Address + Map URLShown in the footer if filled
Social LinksInstagram, TikTok, Facebook
Delivery LinksExample: GrabFood | https://...
Closed MessageCustom message when the shop is closed
Footer TextSmall credit or powered-by line

Upload Logo and Banner

1
Tap Upload Logo to add the square image beside your store name.
2
Tap Upload Banner to add a wide promo image above the menu.
3
Tap Save Store Info.
Tip: Logo and banner upload needs the developer to set an Imgur Client ID once in the Dev tab.

📋 Managing the Menu

The Menu tab lets you add, edit, delete, and mark items as sold out.

Mark an Item as Sold Out

1
Find the item in the list.
2
Tap Sold Out. Customers will see the item greyed out and cannot order it.
3
Tap Enable to make it available again.

Add a New Item

1
Tap + Add Item.
2
Fill in category, name, description, emoji, and optional photo.
3
For drinks, enter Hot, Cold, or Frappe prices. Leave a size blank to hide it.
4
For food, enter one fixed price.
5
Tap Add Item.

Edit, Delete, and Categories

  • ✏️ Tap Edit beside an item to change details, prices, photos, and add-ons.
  • 🗑️ Tap Del only when you really want to remove an item.
  • 🏷️ Use Categories to rename category labels or add a new category.

Add-ons & Options

Choice

A required selection, such as sauce type or spice level.

Optional

A checkbox with an extra price, such as Extra Cheese.

📦 Viewing Orders

The Orders tab shows a log of orders sent through WhatsApp, newest first.

Each entry shows customer name, time, items ordered, add-ons, and estimated total.

Tip: This is a reference log. Actual conversation and fulfilment still happen in WhatsApp.

Tap Refresh to reload latest orders. The app keeps up to 1,000 order records.

🎨 Theme Studio

Theme Studio changes the menu appearance: colours, fonts, and small design tweaks. It uses AI only when you chat with the design helper.

Requires setup: The developer must save an OpenRouter API key in the Dev tab before chat works.

Change Theme by Chat

1
Tap Theme Studio.
2
Type a simple request, for example: "Make it look like a cosy cafe".
3
Tap Send. If you like the result, keep it. If not, restore the last saved theme.

Quick Action Chips

🌸 Seasonal Theme 🎉 Festive Theme ↩ Reset to Default ✏️ Change Slogan 🚫 Category Off ✅ All Available

Upload a Design Template ZIP

A ZIP is a compressed folder. In this app, it means a downloaded HTML template from a design website.

1
Search the web for free restaurant HTML template or free cafe HTML template.
2
Download the template as a ZIP file.
3
Back in Theme Studio, upload it like attaching a photo in WhatsApp.
4
Pick the fonts or colours you want, then apply them.
Tip: If this sounds confusing, skip ZIP upload. The chat and colour picker are enough for most stores.

Factory Reset

Developer login can restore the original master theme if the design becomes messy or unreadable.

🔒 Security & PINs

Change Owner PIN

1
Go to the Security tab.
2
Enter the new 4-digit PIN twice.
3
Tap Update Owner PIN.
Write it down. If both Owner PIN and Developer PIN are lost, your developer must reset it directly in Firebase.

Change Developer PIN

Developer PIN can be changed from the Security tab only when logged in as developer.

🛟 Recovery & Troubleshooting

🔑
Forgotten Owner PIN

Log in with Developer PIN → Security tab → update the Owner PIN.

🎨
Theme Looks Wrong

Log in with Developer PIN → Theme Studio → restore last saved theme or factory reset.

🌐
Page Not Loading

Check internet connection. The app needs Firebase to load live menu and settings.

⚙️
Theme Studio Chat Error

Developer login → Dev tab → check API key, selected model, and Error Log.

Need help? Contact your developer.
